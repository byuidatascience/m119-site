## Quality Guidelines for New Boxes

### Each answer box should include:
1. **Clear problem statement** (what to find/calculate)
2. **Answer with work shown** (not just final answer)
3. **Common mistake note** (if applicable)
4. **Context/interpretation** (why this matters)

### Example Format:
```markdown
Find the derivative of $f(x) = (3x^2 + 1)^5$ using the chain rule.

<details>
<summary>Answer</summary>

Let $u = 3x^2 + 1$, then $f(x) = u^5$.

Using the chain rule: $f'(x) = 5u^4 \cdot u'$

$u' = 6x$

Therefore: $f'(x) = 5(3x^2 + 1)^4 \cdot 6x = 30x(3x^2 + 1)^4$

**Common mistake**: Forgetting to multiply by the inner derivative ($u'$).
</details>
```
